\noindent Миний бие \shortname  ''{\ttitle}'' сэдэвт энэ ажил нь минийх бөгөөд дараахыг нотолж байна. Үүнд:

\begin{itemize} 
\item Энэхүү ажлыг тус сургуулиас боловсролын зэрэг авахаар бүхэлд нь буюу голлон өөрийн хүчээр гүйцэтгэсэн болно.
\item Энэхүү ажлын аль нэг хэсгийг тус сургуульд эсвэл өөр байгууллагад боловсролын зэрэг, мэргэшил авахаар өмнө нь илгээсэн бол түүнийгээ тодорхой дурдсан болно.
\item Бусад хүмүүсийн хэвлүүлсэн бүтээлээс ашигласан бол түүнийгээ зохих ёсоор тэмдэглэсэн болно.
\item Бусад хүмүүсийн ажлаас ишлэл авахдаа эх сурвалжийг нь тодорхой заасан болно.
\item Судалгааны ажилд тусалсан бүх хүмүүст талархал илэрхийлье.
\item Ажлыг бусадтай хамтарч гүйцэтгэсэн бол хэн, ямар хэсгийг хийснийг тодорхой дурдсан болно.
\end{itemize}
